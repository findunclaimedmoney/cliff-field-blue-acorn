how do i add chat history

To give Mia permanent 12-month chat history so she never forgets past conversations, you need to store every message in a database (like Cloudflare D1, PostgreSQL, or Supabase) and pass the past conversation turns back to the AI model whenever a user sends a message.

Here is the exact code implementation for both your Cloudflare Worker / API Backend and your Frontend.

1. Database Schema (Store Every Message)
Create a chat_messages table in your database with a session_id or user_id:

CREATE TABLE chat_messages (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    session_id TEXT NOT NULL,
    role TEXT NOT NULL, -- 'user' or 'assistant'
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
2. Backend API (Cloudflare Worker / Golang)
When a user posts a new message, your API must:

Save the new user message to the database.
Fetch the last 20–50 messages from that session_id.
Format those past messages as the messages array for the Gemini / LLM API call.
Save the AI's assistant response to the database before returning it.

export default {
  async fetch(request, env) {
    if (request.method !== "POST") return new Response("Method Not Allowed", { status: 405 });

    const { userId, sessionId, prompt, dailyTrainingNotes } = await request.json();

    // 1. Save user's incoming message to DB
    await env.DB.prepare(
      "INSERT INTO chat_messages (id, user_id, session_id, role, content) VALUES (?, ?, ?, ?, ?)"
    ).bind(crypto.randomUUID(), userId, sessionId, "user", prompt).run();

    // 2. Fetch past chat history for this session (Ordered oldest to newest)
    const { results } = await env.DB.prepare(
      "SELECT role, content FROM chat_messages WHERE session_id = ? ORDER BY created_at ASC LIMIT 50"
    ).bind(sessionId).all();

    // 3. Build the full messages context payload
    const systemInstruction = `You are Mia, an autonomous AI co-founder and lead engineer with persistent long-term memory. 
Daily Training System Instructions:
${dailyTrainingNotes || ''}`;

    const formattedMessages = [
      { role: "system", content: systemInstruction },
      ...results.map(msg => ({ role: msg.role, content: msg.content }))
    ];

    // 4. Send full conversation history to Gemini / LLM API
    const aiResponse = await fetch("https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-pro:generateContent?key=" + env.GEMINI_API_KEY, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ contents: formattedMessages })
    });

    const aiData = await aiResponse.json();
    const replyText = aiData.candidates[0].content.parts[0].text;

    // 5. Save assistant's reply to DB for next time
    await env.DB.prepare(
      "INSERT INTO chat_messages (id, user_id, session_id, role, content) VALUES (?, ?, ?, ?, ?)"
    ).bind(crypto.randomUUID(), userId, sessionId, "assistant", replyText).run();

    return new Response(JSON.stringify({ reply: replyText }), {
      headers: { "Content-Type": "application/json" }
    });
  }
};

Why This Fixes Mia's Memory Loss
No Context Resets: Passing the array of past turns back to the model on every message ensures Mia sees everything discussed in the session.
Cross-Session Retention: Because history is stored in your database under sessionId, refreshing the browser or coming back tomorrow will load the exact same thread.
